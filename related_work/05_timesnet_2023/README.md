# TimesNet：以多周期重排建模二维变化

## 引用与材料

Wu et al., *TimesNet: Temporal 2D-Variation Modeling for General Time Series Analysis*, ICLR 2023。论文：[arXiv:2210.02186](https://arxiv.org/abs/2210.02186)；官方代码：[THUML/TimesNet](https://github.com/thuml/TimesNet)。本地 `paper.pdf` 为 arXiv v3。

## 要解决的问题

真实序列常有不止一个周期。仅在一维时间轴上建模时，模型要同时处理周期内变化和跨周期演化，表示可能困难。TimesNet 试图先找出主要周期，再把一维序列重排成可用二维卷积表示的张量。

## 核心思路与数据流

1. 从历史窗口的频率信息中自适应选择若干主要周期。
2. 针对每个周期把一维时间序列 reshape 为二维张量：一轴表示周期内位置，另一轴表示跨周期演化。
3. 用 TimesBlock 中的参数高效 inception 风格二维卷积提取两类变化，再融合多个周期的结果。

直觉是把“每天内部的形状”和“每天之间怎样变化”放在不同轴上学习。

## 作者报告的证据

该论文把 TimesNet 定位为通用时序骨干，并报告在短/长预测、插补、分类和异常检测等任务上的结果。当前项目只把它作为**长预测**中的多周期归纳偏置；其他任务成绩不纳入本项目判断。

## 与前后工作的关系

Autoformer 同样强调周期性，但用相关的时间延迟聚合子序列；TimesNet 则显式重排为二维网格并用二维核。它与 PatchTST 一样重视局部结构，但不是 Transformer token 化路线。

## 复现契约

- 候选数据：先 ETTm1（有明显日/周型变化时再扩展到 Electricity/Weather）。
- 协议：保持 `L=96`、四个预测窗和训练段缩放；FFT/周期选择必须只依赖每个输入历史窗口，不能偷看未来。
- 记录：选出的周期、top-k、二维 reshape 尺寸、参数量和每个预测窗误差。
- 最小里程碑：对单个样本画出原始序列与每个周期 reshape 的索引映射，确认没有打乱时间顺序后再训练。

## 局限与待验证问题

- 短窗口可能不足以稳定辨认多个周期；频谱峰也可能是偶然噪声。
- 不规则采样、变化周期或大量缺失会破坏整齐 reshape。
- 二维卷积的优势要与参数量匹配的 1D 卷积、DLinear 比较，不能只和旧 Transformer 比。

# 基础：先建立不会误导自己的预测实验

## 问题定义

多变量预测不是随机样本上的普通回归：每个样本窗口都带有时间顺序，未来标签在训练时不可见。若随机切分窗口，训练和测试可能共享高度重叠的历史片段，从而形成泄漏。

## 必会概念

- **时间切分**：训练最早、验证居中、测试最新；用验证集选模型和超参数。
- **缩放**：每变量只用训练段均值/标准差拟合；测试集不参与任何统计量。
- **基线**：Last/Naive 预测最近值；Seasonal Naive 复制一个季节前的值；ARIMA 是线性自回归与移动平均的经典单变量基线。
- **指标**：MSE 强调大误差，MAE 更稳健；不同量纲变量须同时看逐变量误差。

## 常见陷阱

1. 先对全表做标准化，再切分；这会把测试分布信息送进训练。
2. 用随机窗口划分而不是按时间边界划分。
3. 只比较平均 MSE，忽略某些变量或预测窗崩坏。
4. 用不同输入长度或不同数据版本比较模型，却称为架构优势。

## 复现契约

先在 ETTm1 上实现 Seasonal Naive，再实现 DLinear。所有模型共同使用 `L=96` 和 `H={96,192,336,720}`，同一时间边界与训练段缩放；记录 MSE、MAE、RMSE 和逐变量 MAE。

## 局限

Naive/ARIMA 未必捕获复杂跨变量非线性关系，但它们是检验复杂模型是否真正创造增益的必要下界。ETTm1 只是入门基准，不能代表全部电力、交通或天气场景。
